# 웹·모바일 공통 코드

```text
apps/
├─ web/                  웹 전용 화면·로직
├─ mobile/               모바일 전용 화면·로직
└─ shared/
   ├─ components/        공통 화면 부품
   ├─ contracts/         공통 알림톡 기준
   └─ lib/               공통 화면 도우미
```

독립 실행 앱이나 DB가 아니다. 웹과 모바일이 이 폴더의 같은 파일을 직접 가져온다.

- `form-field`, `mobile-back-button`: 양쪽 구현이 동일해서 하나로 추출했다.
- `app-button`, `app-input`: 구현은 공유하되 기존 웹/모바일 글자 크기·터치 영역·스타일을 각각 유지한다. 앱의 기존 파일은 해당 스타일을 선택하는 재내보내기만 담당한다.
- `contracts/alimtalk.ts`: 기존 문구·버튼·변수 정의를 내용 변경 없이 옮겼다. 원장 확정과 외부 Ssodaa 심사 승인은 별개다.
- 앱별 API, 인증, 결제, 예약 처리, 데이터 모델은 이번 컴포넌트 추출에서 변경하지 않는다.
- 공통 코드는 `@/`나 `apps/web`, `apps/mobile`에 의존하면 안 된다. 앱별 값이 필요하면 외부에서 전달한다.
- 전체 컴포넌트를 한번에 가져오는 통합 파일 대신 필요한 파일만 가져온다.
- 웹/모바일 전역 CSS의 `@source`가 이 폴더를 포함해야 한다. 경로를 옮길 때 함께 검사한다.

다른 UI 컴포넌트는 이름이 같아도 내용이 다르므로 자동 병합하지 않았다. 특히 매장 소개 페이지는 소스가 같아도 앱별 타입·의존 컴포넌트에 연결돼 있어 이번 기초 UI 추출에서는 제외했다.
