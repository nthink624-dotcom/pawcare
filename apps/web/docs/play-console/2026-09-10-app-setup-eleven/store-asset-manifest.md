## 현재 파일 판정

- 현재 `D:\petmanager-app` checkout에서 확인된 PNG는 제품 이미지, Android 아이콘·스플래시와 임시 사진 QA 파일뿐입니다. 승인 가능한 Play 스토어 스크린샷 세트는 없습니다.
- 1300×1300 로고 원본은 아이콘 파생 후보일 뿐이며 512×512 업로드본은 아직 만들지 않았습니다.
- 과거 QA 캡처를 자동 채택하지 않습니다. 현재 accepted manifest와 checkout 해시가 다르고 exact release 화면 증거가 아니기 때문입니다.

## 제작 중단 조건

- 실제 고객·대표·직원 정보, 전화번호, 주소, 사진, 결제 또는 인증 정보가 보임.
- 운영 데이터 화면을 demo/fixture로 위장하거나 demo를 실제 운영 화면으로 설명함.
- 현재 AAB와 다른 과거 UI, 잘린 한국어, 권한 오류, 로딩/빈 화면을 사용함.
- 규격을 맞추기 위해 화면을 비정상적으로 늘이거나 UI 요소를 합성함.
