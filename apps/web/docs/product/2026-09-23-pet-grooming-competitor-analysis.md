### 1페이지 결론

* 모든 업체가 간편접수를 제공하는 것은 아니다. **공식 공개 근거상** 미리멍·PetTech는 보호자 앱에서 날짜·시간을 골라 요청하는 방식이고, flopin은 AI 상담 접수, OROO는 보호자 앱 출시 예정이다. 조사 대상 중 **PetManager처럼 앱 설치 없이 매장별 웹 링크에서 보호자가 시간을 직접 선택하는 공개 근거는 확인하지 못했다**. TEEPEE·GroomerNote·Avoon·BEAUP의 보호자 웹 직접예약은 공개 근거가 부족하다.
* PetManager는 현재 소스에 `매장 예약 링크`·QR·앱 설치 없는 예약 진입, 콜아이디 API, 재방문 링크, 케어리포트, 알림톡 수신/발송 이력이 존재한다. 이는 **소스 구현 상태**이며 운영 채널 심사·프로덕션 가동의 증거는 아니다. 알림톡은 현재 무제한 정책이며, 초과 발송 이용권 판매는 종료 상태다.

### TEEPEE를 이기기 위해 반드시 필요한 기능

기존 링크·알림톡·케어리포트·재방문은 **신규 개발 과제가 아니다**. 실제 격차 후보는 다음 네 가지뿐이다.

1. **예약금 자동 운영** — `예약 상세 > 예약금 요청`에서 금액·기한·미입금 자동취소를 설정하고, 보호자가 결제하면 예약 상태가 바뀌어야 한다.
2. **매장용 전자동의서** — 노령견·공격성·엉킴·호텔링 템플릿, 예약별 발송/서명/열람 이력. 법적 효력 문구는 본인확인·보존정책 검증 뒤에만 쓴다.
3. **선불권·회원권** — `고객 > 이용권`에서 잔여 횟수·유효기간·사용 이력과 예약 차감을 연결한다.
4. **스타일 합의 화면** — `예약 상세 > 지난 사진/원하는 스타일`에서 보호자 사진, 지난 완료 사진, 원장 메모를 나란히 보고 다음 미용 요청에 저장한다.

### 가격·알림톡·링크·케어리포트의 체감 차별화

* **가격:** `월 29,000원(VAT 포함) / 직원 수 제한 없음 / 매장 1곳 / 알림톡 무제한`을 결제 직전에 표로 고정한다. 초과 발송 과금이나 잔여 건수는 노출하지 않는다.
* **알림톡:** 원장은 “누구에게 무엇이 왜 갔는지”를 예약 상세의 `발송 이력`에서 확인한다. 보호자는 **“예약이 확정됐어요”**, **“내일 2:00 예약이에요”**, **“오늘 케어리포트가 도착했어요”**처럼 다음 행동이 하나인 메시지만 받는다.
* **예약 링크:** 매장은 SNS마다 다른 예약 경로를 만들지 않는다. `한 링크`를 네이버·인스타·문자·QR에 쓰고 UTM/채널 태그로 유입 경로만 구분한다. 보호자는 설치·회원가입 벽 없이 예약하고, 이전 고객은 **“지난 정보로 30초 재예약”**을 누른다.
* **케어리포트:** 단순 사진 전송이 아니라 `오늘 한 미용 / 주의할 점 / 집에서 해줄 케어 / 다음 권장일 / 다시 예약`을 한 화면에 담는다. 보호자가 “어떻게 미용됐는지”와 “다음에 무엇을 해야 하는지”를 즉시 안다.

### 미리멍 — 보호자가 예약하는 실제 공개 흐름

1. 보호자는 **미리멍 앱을 설치**한다. 웹 링크에서 예약한다는 공개 근거는 없다.
2. 앱에서 가까운 미용실을 찾고 **원하는 날짜와 시간**을 고른다.
3. 견종별 스타일북에서 스타일을 사진으로 고를 수 있으며, 요청에 그 선택을 담는다.
4. 이 단계는 즉시 확정이 아니라 **예약 요청**이다.
5. 매장은 앱에서 요청을 보고 `확정`, `시간 조정 제안`, `거절` 중 처리한다.
6. 확정되면 보호자에게 카카오 알림톡과 앱 알림이 가고, 하루 전 리마인더가 자동 발송된다.
7. 미용이 끝나면 전후 사진·부위별 건강 체크·메모가 미용 기록으로 남는다.

공식 공개 자료에는 보호자가 예약 단계에서 카드로 결제하는지, 예약금을 내는지, 앱 밖 URL을 공유할 수 있는지는 나오지 않는다. 그러므로 PetManager 대비 미리멍의 정확한 약점은 **앱 설치가 필요하고 매장 링크 유입을 공식적으로 확인할 수 없다는 점**이지, 예약 시간 선택 기능이 없다는 점은 아니다.

### PetTech — 보호자가 예약·주문하는 실제 공개 흐름

1. 보호자는 **PetTech 앱을 설치**하고 휴대폰 인증 사용자로 이용한다.
2. 지도에서 가까운 미용실을 찾고, `당일예약` 표기가 있는 매장도 고를 수 있다. 공식 서비스 지역은 현재 울산·부산이다.
3. 견종별 메뉴와 미용 요금을 **예약 전에** 확인한다.
4. 원하는 **날짜와 시간**을 골라 신청하고, 원하는 스타일 사진도 함께 보낼 수 있다.
5. 예약 금액을 카드로 **선결제**한다. 이는 예약금만 받는 구조가 아니라 앱 설명상 방문 미용 서비스 대금의 선결제다.
6. 매장이 확인·확정하면 알림이 도착한다. 매장은 견종별 메뉴 관리, 예약 확정, 주간 정산을 앱에서 처리한다.
7. 완료 후 사진·미용 리포트가 도착하고, 다음 미용 시기 재방문 알림으로 이어진다.

PetTech의 직접 경쟁력은 고객 유입·선결제·후기/사진 축적이다. 반대로 보호자는 앱 설치·휴대폰 인증·지역 내 입점 매장이라는 조건을 통과해야 한다. PetManager는 한 매장 고객을 인스타·네이버·문자·QR에서 **그 매장 링크로 즉시 전환**시키는 모델이므로, 마켓플레이스 수수료/노출 경쟁이 아니라 기존 단골 예약 채널을 소유한다는 관점으로 비교해야 한다.

### 나머지 경쟁사 판단

| **미리멍** | 공식 공개 자료 없음. 보호자는 앱에서 스타일을 고르고 예약을 신청하는 흐름만 공개됨 | **가능(유료 플랜 조건)**: 예약 확정·취소·변경·전날·미용 완료 안내를 카카오 알림톡으로 발송한다고 공개. 카카오 알림톡 수신 자체는 미리멍 앱 설치를 요구하지 않음 | 공개 자료 없음 | 앱 미설치 보호자도 **이미 잡힌 예약의 안내**는 받을 수 있으나, 전화만으로 미리멍 예약 흐름에 자동 진입한다는 근거는 없음 |
| **PetTech** | 공식 공개 자료 없음. 앱에서 전화 없이 예약하고, 모든 회원은 휴대폰 인증을 거친다고 공개 | 공개 자료 없음. 예약·결제 내역을 앱에서 확인하고, 확정 뒤 `알림`이 온다고만 공개 | 공개 자료 없음 | 앱 미설치 보호자가 PetTech를 통해 예약하거나 PetTech 알림을 받는 대체 경로를 확인하지 못함 |

따라서 미리멍은 `전화/대면 예약 → 원장이 매장 시스템에 등록 → 카카오 알림톡 안내`라는 **사후 접점**은 공개 기능상 가능성이 높지만, 공식 페이지가 “전화 예약을 등록하면 어떤 자동화가 실행되는지”까지 명시하지 않으므로 검증된 흐름으로 단정하지 않는다. PetTech는 앱 기반 중개·선결제 구조로 설명돼 있어, 앱을 설치하지 않은 보호자에게 매장 이용을 연결하는 공개 대체 경로가 확인되지 않는다.

PetManager가 내세울 수 있는 차이는 `고객이 앱을 설치하지 않아도 매장 링크에서 바로 예약`이고, 콜아이디까지 실제 운영되면 `전화 → 기존 고객 자동 식별 → 예약 등록 → 알림톡`이라는 별도 유입 경로가 추가된다는 점이다. 경쟁사에 카카오 알림톡이 있다는 사실만으로 이 전화 유입 자동화와 동일하다고 보면 안 된다.
