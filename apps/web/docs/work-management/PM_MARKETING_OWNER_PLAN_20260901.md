# 펫매니저 마케팅 기획서 — 대표 실행용

기준일: 2026-09-01 · 범위: 반려동물 미용실 PC 오너 SaaS · 외부 발송/광고 집행 0건

## 한 줄 목표

**전화·카카오톡 예약 때문에 미용을 멈추는 소규모 미용실 대표가, 실제 화면을 보고 14일 체험을 시작해 첫 예약까지 만들게 한다.**

## 누구에게 먼저 팔 것인가

1. 1인 또는 소규모 반려동물 미용실: 미용 중 전화·메시지를 놓치고 예약을 수기로 정리하는 매장.
2. 직원이 1명 이상인 미용실: 담당자별 가능한 시간과 예약 겹침을 정리해야 하는 매장.
3. 네이버 예약·카카오톡을 쓰지만 고객/직원 예약이 분산된 미용실.

펫호텔·유치원은 나중입니다. 객실·체크인/아웃·출결 기능은 현재 제품으로 약속하지 않습니다.

## 팔 메시지

> 고객은 가능한 시간을 보고 직접 예약하고, 대표님은 미용을 멈추지 않고 일정만 확인합니다.

- 14일 무료체험
- 체험 시작 시 카드 등록 없음
- 월 29,000원(VAT 포함), 매장 1곳당 단일 월 정기 이용
- 직원 수 제한 없음, 다점포는 매장별 별도 구독
- 실제 화면을 먼저 보여주고 가입을 권한다

알림톡·AI 제공량/원가 한도는 확정 전 공개 숫자나 “무제한” 표현을 쓰지 않습니다. 환불·청약철회는 고객센터 접수 후 관련 법령과 실제 제공 여부를 기준으로 안내하며, 고정 환불액·기한은 별도 확정 전 약속하지 않습니다.

## 이렇게 할 것

| 순서 | 할 일 | 이유 | 완료 기준 |
|---|---|---|---|
| 1 | 가격·환불·약관의 예전 다중 플랜 문구 정정 요청 | 한 가지 요금이라고 말해도 믿을 수 있게 | 랜딩/FAQ/환불/약관이 같은 사실을 말함 |
| 2 | 랜딩에서 실제 예약 화면 → 14일 체험 → 월 29,000원 순서로 보이게 준비 | 가격보다 먼저 ‘내 매장에서 쓰는 모습’을 이해시킴 | 화면 보기/가입 CTA가 준비됨 |
| 3 | 네이버 검색용 글 2편 준비 | 돈 없이 예약 문제를 찾는 대표에게 발견됨 | 글 초안 2편, CTA 1개씩 |
| 4 | 3분 비동기 설문 준비 | 어떤 예약 문제가 실제로 큰지 확인 | 설문/감사/셀프 소개 링크와 수신거부 준비 |
| 5 | 파일럿 결과 후 검색 광고 1개만 테스트 | 맞는 메시지에만 광고비를 씀 | 대표 승인 범위 내 300,000원 이하, 그 전 집행 0 |

## 첫 4주 일정

| 주 | 해야 할 일 | 대표가 보는 결과 |
|---|---|---|
| 1주 | 승인된 단일 요금 기준의 랜딩/FAQ/약관 정정안 인계 | 가격을 헷갈리지 않는 한 장의 화면 |
| 2주 | 네이버 검색 글 2편 완성 | `애견미용 예약 받을 때 꼭 정할 3가지`, `예약이 겹치지 않게 만드는 기본 설정` |
| 3주 | 3분 설문·자동 감사·제품 소개 링크 준비 | 파일럿 준비 완료 여부 |
| 4주 | 설문/파일럿 반응 요약, 가장 반응 좋은 메시지 1개 선정 | 광고를 해도 되는지 판단 자료 |

## 확인할 숫자

- 랜딩 방문 → 실제 화면 보기 → 가입 시작 → 초기 설정 완료 → 첫 예약 → 7일 사용
- 설문에서는 “예약을 어디서 놓치는지”, “지금 쓰는 도구”, “월 29,000원에서 망설이는 이유”만 확인
- 광고는 파일럿에서 반응이 확인된 뒤에만 1개, 총 300,000원 이하

## 초기 협력 매장 혜택 — 확정 운영안

대상은 처음 참여하는 **20개 미용실**입니다. 정식 할인보다 실제 사용 시간을 보상하는 방식으로 운영합니다.

| 혜택 | 기준 |
|---|---|
| 기본 체험 | 14일 무료체험, 시작 시 카드 등록 없음 |
| 초기 협력 혜택 | 첫 유료 결제가 완료되면 이용기간 30일 추가 |
| 큰 문제 보상 | 로그인·예약·결제가 막히는 확인된 문제는 14일 추가 |
| 핵심 문제 보상 | 예약 정보·시간 오류 또는 핵심 운영 기능 실패가 확인되면 7일 추가 |
| 최대 보상 | 첫 결제 30일 연장과 별도로, 첫 유료 결제일부터 3개월 동안 문제 보상 최대 60일 |
| 응답 약속 | 신고를 받으면 1영업일 안에 접수·확인 상태를 안내 |
| 먼저 써보기 | 준비가 끝난 새 기능만 초기 협력 매장에 먼저 제안 |

### 운영 기준

- 같은 문제의 중복 신고, 사용법 문의, 새 기능 요청, 외부 서비스 장애는 기간 보상 대상이 아닙니다.
- 기간 연장은 문제 재현·확인 뒤에만 적용합니다. 첫 단계에서는 관리자가 수동으로 처리하며 자동 보상 기능을 약속하지 않습니다.
- 평생 할인, 무제한 무료 이용, 모든 불편의 자동 보상은 제공하지 않습니다.

### 고객 안내 문구

> 초기 협력 매장은 14일 무료체험 후 첫 결제 시 30일을 더 드립니다. 사용 중 확인된 문제는 우선 수정하고, 문제 수준에 따라 이용기간도 추가해 드립니다.

## 지금 멈춰 있는 것

1. 공식 발신 계정: 파일럿 1순위 채널은 공식 펫매니저 인스타그램 사업 계정의 PC DM이다. 계정 연결·접근 권한·발신자 식별이 아직 없으므로 실제 DM은 0건이다. 인스타 DM이 불가능한 매장만 공개 사업용 이메일을 보조 채널로 사용한다.
2. 설문: 실제 공개 설문 URL·제출 후 감사 안내·셀프 제품 소개 URL이 아직 없습니다. 계정 생성이나 외부 게시 없이 설문 문항과 안내 문구만 준비합니다.
3. 제품 배포: 기술팀의 lint 오류 정리와 배포 범위 정리가 끝나기 전 공개 화면을 근거로 한 발송·콘텐츠 게시를 하지 않습니다.

## 이번 주 마케팅 준비물

### 3분 비동기 설문 (초안)

고객·반려동물·예약 정보는 묻지 않는다. 답변은 운영 형태와 문제 유형만 수집한다.

1. 운영 형태: 1인 / 2~4인 / 5인 이상
2. 예약 문의가 가장 많이 들어오는 곳: 전화 / 카카오톡 / 네이버 예약 / 인스타그램 / 기타
3. 가장 자주 생기는 문제: 미용 중 응답 지연 / 예약 겹침 / 빈 시간 관리 / 가격·소요시간 설명 / 고객 정보 정리 / 기타
4. 가격과 소요시간을 현재 어떻게 관리하는지: 종이·메모 / 엑셀·노션 / 예약 서비스 / 기타
5. 고객 예약 페이지에 꼭 있어야 할 정보: 최대 2개 선택 (가능 시간 / 가격 / 소요시간 / 담당자 / 요청사항 / 위치·연락처)
6. 월 29,000원(VAT 포함)·매장 1곳·직원 수 제한 없음·14일 체험(카드 불필요)을 본 뒤 가장 망설이는 이유: 가격 / 다점포 별도 구독 / 현재 도구 유지 / 데이터 이전 / 기능 확인 필요 / 기타 짧은 답변
7. 제품 화면 보기: 원함 / 원하지 않음

제출 즉시 감사 안내만 보낸다. `제품 화면 보기`를 고른 매장에만 녹화된 3분 소개 또는 셀프 가입 링크를 자동 제공한다. 전화·라이브 데모·자동 리마인드·대체 접촉은 하지 않는다.

### 인스타그램 DM 1회 모집 문구 (초안)

> 안녕하세요, 펫매니저입니다. 반려동물 미용실의 실제 예약 운영 불편을 이해하기 위한 3분 설문을 준비하고 있습니다. 영업 제안이 아니며 고객·반려동물·예약 정보는 묻지 않습니다. 참여하실 수 있다면 설문에 답해 주세요. 답변이 없으면 다시 연락드리지 않겠습니다.

CTA는 `3분 설문 참여` 하나만 둔다. 최근 운영 흔적이 있고 공개된 사업용 인스타그램 계정에만 후보당 PC DM 1회 발송한다. DM을 보낼 수 없는 매장만 공개 사업용 이메일로 1회 보조 발송한다. 한 후보에게 두 채널을 모두 사용하지 않으며, 거부·무응답·수신거부는 추가 연락 없이 종료한다.
