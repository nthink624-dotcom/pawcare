# AI 예약 추천·빠른 예약 배정 가이드

## 역할 분리

펫매니저가 예약의 판단 주체다. DeepSeek는 펫매니저가 계산해 전달한 `availableSlots` 안에서 **추천 순서만** 정한다. AI는 예약 가능 여부, 담당자 배정, 예약 생성·변경·취소를 결정하지 않는다.

## 시간 추천 기준

1. 영업시간, 휴무, 예약 금지 시간, 서비스 소요 시간, 직원 근무시간, 동시 수용 인원, 기존 예약과의 겹침을 통과한 시간만 `availableSlots`에 넣는다.
2. `availableSlots`는 서버 내부의 후보 집합이다. 고객에게는 그중 AI(또는 안전한 규칙 대체)가 고른 최대 4개만 보여 준다.
3. 기존 예약의 앞뒤 빈 시간을 줄이는 후보를 먼저 추천한다.
4. 비슷한 후보라면 너무 이르거나 늦은 시간보다 실용적인 주간 시간을 우선한다.
5. 추천 4개는 가능한 한 서로 다른 시간대로 보여 준다. 같은 선택지를 촘촘히 반복 추천하지 않으며, 별도의 전체 시간표는 고객에게 노출하지 않는다.
6. AI 실패·시간 초과 시에도 규칙 기반 추천으로 즉시 예약을 계속할 수 있어야 한다.

## 디자이너 선택·빠른 예약 배정 기준

1. 고객이 디자이너를 직접 선택하면 그 선택은 절대 변경하지 않는다.
2. 고객이 `빠른 예약`을 선택하면, 고객이 고른 시간과 서비스에서 가능한 디자이너만 후보로 삼는다.
3. 후보 중 해당 날짜의 확정 예약 시간이 가장 적은 디자이너를 배정한다.
4. 예약 시간이 같으면 예약 건수가 적은 디자이너를 우선하고, 그래도 같으면 안정적인 디자이너 ID 순서로 정한다. 무작위 배정은 하지 않는다.
5. 예약 생성 직전에 다시 가능 여부를 검증한다. 동시 요청이라도 근무·중복 방지 규칙이 최종 기준이다.

## DeepSeek 전달 규칙

- 입력: 계산 완료된 `availableSlots`, 규칙 기반 빈 시간 절감 후보, 서비스 소요 시간, 날짜.
- 출력: `{"recommendedSlots":["HH:mm"]}` 형식의 최대 4개 시간 순서.
- 금지: 입력에 없는 시간 생성, 직원 배정·변경, 예약 생성·취소, 고객이 선택한 담당자 변경.
