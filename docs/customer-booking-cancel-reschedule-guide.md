# 고객 예약 취소·변경 가이드

## 취소

1. 고객이 예약 취소를 완료하면 해당 예약의 상태를 즉시 `cancelled`로 바꾼다.
2. `cancelled`, `rejected`, `noshow` 예약은 예약 가능 시간 계산을 막지 않는다. 따라서 취소된 예약의 시간은 즉시 다시 예약 후보가 된다.
3. 고객 예약 화면은 취소 성공 후 예약 가능 시간 캐시를 무효화하고, 다음 조회부터 서버의 최신 가능 시간을 사용한다.
4. 취소 가능한 대상은 아직 시작하지 않은 `confirmed` 예약이다. 시작했거나 완료된 예약은 고객 화면에서 직접 취소하지 않는다.

## 변경

1. 예약 변경은 기존 예약 행을 새로 만들지 않고, 기존 행의 서비스·날짜·시간·메모를 갱신한다.
2. 변경 시간을 계산할 때는 변경하려는 예약 자신을 충돌 계산에서 제외한다. 그래서 같은 시간으로 내용을 수정하는 것도 가능하다.
3. 담당 디자이너는 기존 담당을 유지한다. 고객이 직접 고른 담당이거나 빠른 예약으로 자동 배정된 담당 모두 변경 과정에서 임의로 바꾸지 않는다.
4. 변경 화면에는 해당 담당 디자이너가 변경할 서비스와 날짜에 실제로 가능한 시간만 보여 준다.
5. 변경이 확정되면 기존 시간은 즉시 다시 예약 가능 시간으로 돌아가고, 새 시간은 즉시 점유한다.
6. 원하는 시간에 기존 담당이 불가능하면 다른 담당으로 자동 이동시키지 않는다. 고객은 별도 새 예약 또는 매장 문의를 통해 담당 변경을 선택한다.

## AI·빠른 예약과의 관계

- AI는 변경 화면에서도 실제 가능 시간 중 추천 순서만 제시한다.
- 빠른 예약은 최초 예약 시에만 가능한 담당 중 업무량이 적은 담당을 자동 배정한다.
- 예약 변경은 담당 연속성과 고객 기대를 우선하므로, 기존 담당을 유지한다.
