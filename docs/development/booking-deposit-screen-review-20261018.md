## 중복 요청을 화면에서 확인하는 법

- **같은 날 복수 예약**: 체험01은 10월 19일 10시/12시 두 반려견 예약. 고객·오너 상세에 ‘같은 날 예약 2건이 예약금을 한 번만 나눠 사용’ 안내가 있다. 첫 예약에서 확인하면 두 예약의 차감 예정 합계가 2만원을 넘지 않는다.
- **첫 실제 입금 후 추가 예약**: 체험02는 첫 미용 이력 0건이며 10월 19일 첫 예약금 2만원이 실제 확인된 테스트 상태다. 10월 20일 14시 추가 예약은 추가 입금 없이 확정돼 있다. 고객별 설정은 ‘항상 요청’이 아닌 매장 정책 따르기다. 같은 조건으로 신규 예약을 입력해도 첫 방문 이유만으로 재요청하지 않는다. 노쇼/항상 요청 조건은 별도다.
- **같은 날 일부 취소**: 10월 21일 체험07의 10시 예약은 취소됐지만 12시 남은 예약에 2만원이 그대로 유지되고 환불액은 0원이다.
- **최종 정산**: ‘최종차감’은 서비스 금액 25000원, 실제 확인 30000원으로 차감 25000원/환불 대기 5000원이다. ‘정산완료’는 날짜 승계까지 거친 별도 예시라 해당 날짜에서 직접 확인한 입금 총액과 승계 자금이 다르다.

## 환경설정 확인

이번 화면 준비 작업에서는 `.env.local`, `apps/web/.env.local`, `apps/mobile/.env.local`, `backend/alimtalk-relay/.env`를 수정하지 않았다. 시작 때 저장한 해시와 마지막 해시가 같다. 웹/모바일/CLI는 지정 개발 ref이며 알려진 공유 보안 설정 원본도 개발 ref였다. 임의 동기화/이전 값 덮어쓰기는 하지 않았다.

현재 브라우저의 기본 매장 선택과 매장 이미지 캐시는 이번 작업 시작 때의 해시와 같다. 인증 세션을 다른 계정으로 교체하거나 storage 전체를 지우지 않았다. 과거 구현 검사에서 유실된 **더 이전** 로컬 환경설정의 정확한 값은 복구 근거가 없어 여전히 미확인이다. 현재 API/DB에는 영향이 확인되지 않았지만 과거 화면 표시 선호값을 완전 복원했다고 주장하지 않는다.

`petmanager.ownerWeb.settings`는 이번 시작 당시 키 존재만 기록했고 값의 기준 해시는 확보하지 않아 정확한 전후 값 비교는 미확인이다. 기존 값을 추정해 덮어쓰지 않았다. 예약금 정책·대상·금액 원장은 개발 DB의 정본을 사용하며 이 로컬 값으로 덮지 않는다. 예약금 테스트의 통과가 과거 로컬 설정 전체 복구를 의미하지는 않는다.

추가 예약 입력을 살펴보며 앱이 생성한 `petmanager:booking-profile`은 시작 때 없었고 내용이 이번 가상 보호자인 경우만 확인하여 정리했다. 인증/개인 프로필 전체 삭제는 하지 않았으며, 열어 둔 제출 전 입력 화면은 그대로다. 예약금 개발에 필요한 개발 DB 연결이나 발송 차단 설정은 유지했다.

개발 `CRON_SECRET`은 없으며 새로 넣지 않았다. 개발 유지보수 API의 외부 호출은 401, 장기 Next 프로세스의 개발 15초 interval은 실제 최근 실행 시각 갱신과 오류 없음으로 확인했다. `NODE_ENV=development`는 검사 프로세스에서만 사용했고 프로세스 종료 후 남는 설정이 아니다.

준비된 항목: 직접 열 수 있는 개발 화면/전용 데이터, 캘린더의 재접속 환불 경로, 매장 분리 권한, 공통 유지보수 실행 경로/검사, 환불 고지·동의·계산 일치 검증, 비활성 매분 스케줄러 설정안.

남은 항목: 템플릿 승인/활성/매핑과 실제 운영 릴레이 연결 확인, 실제 발송 검증 승인, Vercel 요금제·웹 endpoint 배포 경로 확인 및 지속 실행 활성화 승인, 실제 매장 환불 약관의 법적 적합성 검토. [운영 준비 세부 기록](booking-deposit-operations-20261018/README.md)에 구분했다.

이번 작업에서 운영 DB는 공용 템플릿 mapping만 읽었다. 운영 데이터 쓰기/운영 배포/push/커밋/실제 메시지 발송은 하지 않았다. 기존 보호자·예약·예약 준비 6건의 해시는 이번 전용 fixture를 제외하고 이전 검증과 같다. 개발 전체 스키마 정비로 범위를 넓히지 않았다.
