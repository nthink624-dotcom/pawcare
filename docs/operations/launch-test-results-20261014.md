## 운영 화면·API

- 로그인된 오너 메뉴 9개를 열어 화면 표시와 가로 넘침을 확인했다. 수집한 브라우저 자바스크립트 오류는 0건이다.
- 일정, bootstrap, 매출, 구독, 미디어 목록, 예약 정책, 승인 템플릿 미리보기 GET 응답이 HTTP 200이었다. 화면을 열고 조회한 증거이며 전체 생성·수정·삭제 흐름의 증거는 아니다.
- 로그인한 자기 매장 정책 조회는 200, 다른 매장 조회는 403이었다. 고객 행을 조회하거나 변경하지 않고 권한 경계를 확인했다.
- 로그인 없는 예약 정책, 관리자 오류 조회, 오류 정리 호출은 각각 401이었다.
- 검사 시작 시 웹은 `8b0f079d`였다. 검사 도중 별도 작업의 모바일 사진 UI 커밋 `af612b4c`가 원격 master/모바일 운영에 반영되었다. 변경은 모바일 컴포넌트 두 개였으며 이 변경 이후 추가 사진 검사와 모바일 TypeScript 검사를 실행했다. 웹은 기존 커밋에 있어 두 배포 SHA가 다르다. SHA 불일치를 HTTP 장애로 간주하거나 다른 작업 배포를 덮어쓰지 않았다.
