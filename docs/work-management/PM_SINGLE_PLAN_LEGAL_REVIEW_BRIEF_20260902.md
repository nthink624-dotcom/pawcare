# 펫매니저 단일 요금제 법무 리스크 검토 기록

- 기준일: 2026-09-02 (KST)
- 상태: **내부 리스크 검토 완료** — 이 문서는 법률 자문이나 법적 적합성 보증이 아니다.
- 대상: 반려동물 미용실 오너가 사용하는 월 구독형 SaaS

## 1. 확정된 상업 정책

- 월 29,000원, VAT 포함
- 구독당 매장 1곳, 직원 수 제한 없음
- 다점포는 매장별 별도 구독
- 14일 무료체험, 시작 시 카드 불필요, 체험 종료 뒤 자동결제 없음
- 유료 전환은 이용자가 직접 동의하고 카드 등록·결제를 완료할 때만 시작
- 알림톡·AI는 제공량/원가 한도 확정 전 공개 숫자·무제한 표현을 사용하지 않음

## 2. 내부 검토에서 확인한 질문

1. 실제 가입 주체와 이용 목적을 기준으로 전자상거래법상 `소비자` 해당 여부 및 B2B SaaS 약관에 적용할 법령 범위를 확인해 주세요.
2. 유료 결제 뒤 월 이용기간이 시작된 경우의 환불·청약철회·해지 문구를 확인해 주세요. 특히 “해당 월 이용분은 환불되지 않는다”는 현행 초안이 적용 법령과 실제 제공 방식에 맞는지 판단이 필요합니다.
3. 소비자에게 청약철회 제한이 적용될 가능성이 있는 경우, 사전 고지·명시적 동의·시험 사용 제공 등 필요한 절차와 화면 문구를 확정해 주세요.
4. 정기결제의 결제 전 고지 항목, 해지 경로, 다음 결제일 표시, 환불 처리 기준·기한을 검토해 주세요.
5. 약관의 분쟁 관할 조항과 사업자·고객센터 표시 항목이 적용 법령 및 약관규제 기준에 맞는지 확인해 주세요.

## 3. 공개 문구에 적용한 보수적 기준

| 대상 | 적용 기준 |
|---|---|---|
| `src/lib/auth/owner-paid-service-terms.ts` 제7조 | “해당 월 이용분은 환불되지 않는다”는 단정 대신, 고객센터 접수 후 관련 법령과 실제 제공 여부를 기준으로 안내 |
| `src/app/refund/page.tsx` | 체험·직접 결제·다음 결제부터 해지 사실과 환불/청약철회 접수 기준을 함께 안내 |
| 랜딩/결제 화면 | 14일 체험, 카드 불필요, 체험 종료 자동결제 없음과 결제 전 가격·VAT·매장 기준을 표시 |
| 약관 제9조 및 가입 약관 제13조 | 회사 소재지 관할을 단정하지 않고, 대한민국 법령과 절차에 따라 해결한다고 안내 |

## 4. 공식 확인 근거 (2026-09-02 확인)

- [전자상거래 등에서의 소비자보호에 관한 법률](https://www.law.go.kr/lsInfoP.do?lsId=009318) — 통신판매와 소비자 관련 정의·전자문서 절차를 확인할 공식 원문.
- [전자상거래법 시행령 제2조](https://www.law.go.kr/LSW/lsSc.do?eventGubun=060101&menuId=1&query=%EC%A0%84%EC%9E%90%EC%83%81%EA%B1%B0%EB%9E%98+%EB%93%B1%EC%97%90%EC%84%9C%EC%9D%98+%EC%86%8C%EB%B9%84%EC%9E%90%EB%B3%B4%ED%98%B8%EC%97%90+%EA%B4%80%ED%95%9C+%EB%B2%95%EB%A5%A0+%EC%8B%9C%ED%96%89%EB%A0%B9&section=&subMenuId=15&tabMenuId=81) — 소비자 범위 판단 시 검토할 공식 원문.
- [콘텐츠산업 진흥법 제27조](https://www.law.go.kr/LSW/lsInfoP.do?ancYnChk=0&lsId=009280) — 디지털 콘텐츠의 청약철회 제한·사전 조치 관련 공식 원문.

## 5. 공개 시 계속 지킬 제한

- “결제 후 환불 불가”, “청약철회 불가”, “회사 소재지 법원만 관할”을 최종 정책처럼 공표·배포하지 않음.
- 실제 환불 금액·기한·예외는 접수 사례와 적용 법령을 기준으로 안내하며, 화면에 임의의 일률 기준을 추가하지 않음.

## 6. 배포 전 실행 순서

1. 랜딩/FAQ와 실제 결제 화면의 가격·매장·직원·체험 문구를 대조한다.
2. 실제 화면·결제 흐름 검수와 배포 전 검사를 통과한다.
3. 배포 후 실제 환불·청약철회 문의가 생기면 운영팀이 이 문서의 공식 근거와 실제 제공 사실을 함께 확인한다.
