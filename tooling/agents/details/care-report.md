# 케어리포트·미용 사진 상세 규칙

이 파일은 케어리포트 작성·생성·전송, 미용 전후 사진, 미용 시작/완료 사진 흐름을 다룰 때만 읽는다.

## 예약·반려동물 결속

- 케어리포트와 미용 사진은 정본 예약 ID, 반려동물 ID와 미용 기록에 결속한다. 화면 순서나 이름만으로 연결하거나 다른 반려동물 자료를 재사용하지 않는다.
- 고객에게 보이는 케어리포트는 저장된 정본 기록의 projection이어야 하며 화면별 독립 복사본이나 production fallback 보고서를 만들지 않는다.
- 기존 미용 전후 사진과 durable media ID는 명시적 사용자 삭제가 없으면 보존한다. 부분 업로드·재시도·signed URL 실패가 기존 목록을 최신 응답 한 건으로 덮어쓰면 안 된다.

## 미용 시작·상태 변경

- 미용 시작 사진 촬영은 선택 사항이며 PC, 모바일, seed, 수동 API 호출 어디에서도 상태 변경을 막는 필수 조건이 아니다.
- 미용 시작 시 `사진 촬영 후 시작`과 `사진 촬영 없이 시작`을 선택하게 한다. 촬영 선택은 사진 저장 후 상태를 바꾸고, 미촬영 선택은 즉시 상태를 바꾸며, 취소는 아무것도 바꾸지 않는다.
- `픽업 준비`는 미용 완료 전 픽업 안내 동작이다. 완료 상태가 아니며 사진을 요구하지 않는다. 알림 설정, 수신 거부, 중복 방지, 승인 템플릿과 크레딧 규칙을 그대로 적용한다.
- AI가 케어 문구를 만들더라도 예약·반려동물 사실을 추측하거나 다른 기록을 섞지 않는다. 외부 AI 전송 범위와 개인정보 처리가 확인되지 않았다면 안전·보관 주장을 하지 않는다.
