# 요금표 상세 규칙

이 파일은 PC 또는 모바일에서 상세 요금표의 편집, 사진 분석, 검토, 저장, 고객 노출, 예약 가격·시간 계산을 다룰 때만 읽는다.

## 단일 데이터 원본

- 고객에게 보이는 미용 메뉴는 저장된 상세 요금표의 읽기 전용 projection이다. 독립적인 고객용 가격/시간 행, fallback 서비스 가격, 데모 행, 오래된 복사값을 만들지 않는다.
- 노출 설정에는 순서, 공개 여부, 원본 연결 같은 표현 정보만 저장한다. 가격, 소요시간, 동물종, 견종 그룹과 서비스 항목은 상세 요금표 원본 행에서 가져온다.
- 사진 분석 미리보기는 소유자가 확인하기 전 저장 정본이 아니다. 모호한 값은 추측하지 않고 `미확인` 또는 해당 스키마의 unknown/null 상태로 남긴다.
- 최종 저장 전 클라이언트와 서버가 같은 엄격한 스키마를 검증하며, 소요시간이나 가격을 임의 기본값으로 채우지 않는다.

## 요금표 UI 하드 계약

- 이 섹션은 PC, 모바일, 검토 fixture와 증거 HTML의 모든 요금표 편집·검토 화면에서 일반 dense-table 규칙보다 우선한다.
- 표 헤더, 몸무게/서비스 라벨, 동작 라벨, 검증 메시지, 가격, 소요시간은 `16px/24px`를 사용한다. 그룹명은 `20px/28px`, 견종 목록은 `18px/26px`다. 요금표 안에서 12px 또는 14px를 쓰지 않는다.
- 서비스 헤더에는 원본 서비스명만 표시한다. 각 서비스 셀은 가격을 왼쪽, 예상시간을 오른쪽에 둔 한 개의 수평 행이며 둘 다 `white-space: nowrap`을 유지한다.
- 그룹명은 weight 600, 서비스·첫 열 헤더는 500, 견종 목록·몸무게·가격·시간은 400을 사용한다. 모든 라벨과 값을 굵게 만들지 않는다.
- 그룹명과 견종 목록은 얇은 구분선이 있는 한 개의 wrapping flex 행에 두고, 공간이 부족할 때만 견종 목록을 아래로 감싼다.
- 소요시간이 없으면 오른쪽 시간 칸에 `미정`을 표시하고 수평 구조를 유지한다. 원본 명칭이 체급·무게여도 첫 열 표시는 항상 `몸무게`다.
- 조작 대상은 최소 44px를 유지한다. 실제 2차원 overflow는 표 컨테이너 안에 가두고, 표를 맞추기 위해 글자를 줄이지 않는다.
- 정본 구현 파일은 `PRICE_GUIDE_UI_HARD_CONTRACT` 표식을 유지한다. 계약 테스트는 12/14px, 가격·시간 적층, nowrap 누락, 44px 미만 조작을 실패시켜야 한다.
- 완료 증거는 1440, 1024, 430, 390 너비의 computed style과 geometry를 포함한다. 가격과 시간의 상단 좌표가 같고 페이지 전체 가로 overflow가 없어야 한다.
