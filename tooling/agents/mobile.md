## 모바일 웹/App 전용 규칙

### 저장소와 책임

- 이 출력은 `D:\petmanager\apps\mobile`에서만 적용한다. 모바일 웹과 Capacitor 기반 하이브리드 앱, Android 네이티브 셸, AAB와 Play 준비가 이 저장소의 범위다.
- PC 관리자·오너 데스크톱 화면, 공유 백엔드/API 구현, Supabase 마이그레이션은 여기서 구현하지 않는다.
- 모바일은 공용 API와 데이터 계약을 소비하며, 공유 필드·상태 의미를 임의로 바꾸거나 직접 DB 쓰기로 백엔드 계약을 우회하지 않는다.

### 모바일 화면

- 주요 앱 화면은 최대 430px를 기준으로 흰색 기반의 단순하고 앱다운 구조를 유지한다.
- 오너와 스태프가 같은 앱을 쓰더라도 로그인 역할에 맞춰 정보와 조작 범위를 나눈다. 스태프 모드는 명시적 승인 없이 다른 스태프의 예약을 노출하지 않는다.
- 제거된 데모·과거 모바일 흐름을 활성 경로에 다시 넣지 않는다.
- 카메라와 미용 사진 흐름은 모바일 핵심 기능이다. 명시적 요청 없이 필요한 촬영·선택·업로드 흐름을 제거하거나 우회하지 않는다.

### 모바일 로컬과 3100 포트

- 모바일 웹/App 로컬 개발 origin은 `http://127.0.0.1:3100`이다. PC 대표용 3000 포트와 혼용하지 않는다.
- 기기 연결·Capacitor 동기화 전에 3100 서버와 앱이 사용하는 endpoint를 확인한다. 포트 연결만으로 DB 환경이나 운영 연결을 추정하지 않는다.
- 작업이 시작한 3100 서버·Android 연결·자동 브라우저만 소유권을 확인해 정리하고 다른 작업이나 개인 프로세스는 종료하지 않는다.

### Capacitor·Android·AAB·Play

- Capacitor/Android 변경과 네이티브 동기화는 `D:\petmanager\apps\mobile` 원본에서만 수행하고 생성 결과가 최신 웹 소스를 포함하는지 확인한다.
- APK/AAB 빌드, 서명 AAB, 기기 실행, Play 업로드, 심사 제출, 공개는 각각 다른 상태다. 앞 단계 성공을 다음 단계 완료로 보고하지 않는다.
- Play Console 선언·업로드·제출·공개는 대표가 승인한 정확한 범위에서만 수행한다. 좁은 저장 요청은 저장 후 readback하고 최종 제출·공개 전에 멈춘다.

### 모바일 상세 규칙 라우팅

- Capacitor, Android Studio, AAB, 실기기, Play Console, 모바일 릴리스: `D:\petmanager\tooling\agents\details\deployment-mobile.md`
- 모바일 UI 파일 구조·크기 조정: `D:\petmanager\tooling\agents\details\ui-structure.md`
- 모바일의 알림 UI·문구·상태 작업은 공통 `alimtalk.md` 계약만 읽으며 백엔드 릴레이 운영 절차를 자동으로 불러오거나 모바일 저장소에서 실행하지 않는다.
- 공통 기능 상세는 공통 규칙의 라우팅 표에서 현재 작업에 해당하는 파일만 읽는다.
